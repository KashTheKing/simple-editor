---
description: Record a goal in goals.md and implement it right now
argument-hint: <the goal to set and pursue>
---

Read [agents.md](../../agents.md), [goals.md](../../goals.md), and [notes.md](../../notes.md) first.

Goal: $ARGUMENTS

1. Add it to goals.md under "In progress / open" as a checkbox item (same rules as `/se-goal` —
   don't duplicate an existing entry).
2. Immediately pursue it: read the relevant code, make a plan proportional to its size (a
   one-liner doesn't need a written plan; a multi-file change does — use a worktree per
   agents.md if it's non-trivial).
3. Implement it, respecting goals.md's core goals and "things to avoid" — if the goal as stated
   conflicts with the size/dependency budget or a UX anti-pattern, flag that before proceeding
   rather than silently violating it.
4. Verify per agents.md's Verification section.
5. Check the box in goals.md once it's actually done (verified, not just written). If it's only
   partially done, leave it unchecked and note the remainder in notes.md.
