---
description: Record a new goal or priority in goals.md (does not implement it)
argument-hint: <the goal to add>
---

Read [goals.md](../../goals.md) first.

Add this goal: $ARGUMENTS

1. Decide where it belongs: "Core goals" (a lasting non-negotiable), "In progress / open" (a
   concrete todo), or "UX principles" / "Things to avoid" (a design rule). Don't duplicate an
   existing entry — if one's close, sharpen/merge it instead.
2. Add it as a checkbox item (if actionable) or a bullet (if a principle/constraint), matching the
   existing style in that section.
3. Do not start implementing it. This command only records.
4. Confirm what you added and where.
