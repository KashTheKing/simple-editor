Right-click reference

Simple Editor keeps its panels clean by putting the less common commands in right-click menus: right-click the thing you want to change. Menu items show their shortcut on the right, and greyed-out items say why when you hover them. "▸" opens a submenu.

Window and panels​

Right-clickMenu
A page button (Edit, Color…)Reset Page Layout · Reset to Built-in Layout
A panel's tabMaximise panel · Undock · Close · Stay on this tab · Set Icon ▸
Any menu itemSet Icon ▸ (give that command a different icon)
A project in File ▸ Open RecentRemove from recent
