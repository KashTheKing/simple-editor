The interface

The window has three parts: the menu bar at the top, with the page buttons in its middle, and the panels below it. Each panel sits in a group with tabs along its top.

Pages​

Pages are ready-made arrangements of panels for one kind of work, in the same order as Resolve's pages. Switch with the buttons in the middle of the menu bar, Window ▸ Pages, or Alt+1–Alt+6. The Inspector is in the top-right corner of every page.

PageKeyWhat's on it
MediaAlt+1Library · Source · Inspector, full height. Bringing in, sorting and watching media.
CutAlt+2Library · Source / Preview · Inspector on top, the Timeline below. Quick cutting.
EditAlt+3Library (with Effects, Transitions, Gallery) · Source / Preview · Inspector, the Timeline below. The page the app opens on.
ColorAlt+4Gallery (Looks, LUTs) · Preview · Inspector, a thin Timeline, then Nodes / Curves · Scopes.
AudioAlt+5A small Preview · Mixer / Subtitles · Inspector, with a tall Timeline for audio tracks.
ExportAlt+6Export settings · Preview · Inspector over Jobs (the render queue), with the Timeline below.

Every page remembers its own arrangement. Changing the Color page never touches the Edit page.

Make an arrangement the page's default with Window ▸ Layout ▸ Save as This Page's Default. Then:

  • Reset Page Layout (in Window ▸ Layout, or right-click the page's button) goes back to your default, or to the built-in one if you haven't saved one. Ctrl+Z undoes it.
  • Reset to Built-in Layout goes back to the page as it came with the app.

Panels​

PanelWhat it's for
LibraryYour imported media, sequences and folders (Library)
SourceWatch a clip from the Library and mark the part you want (Source monitor)
PreviewThe program monitor: what your edit looks like (Viewer)
TimelineWhere you arrange and cut clips (Timeline)
InspectorSettings of whatever is selected (Inspector)
Effects, Transitions, GalleryThings to add to clips (Effects, transitions & titles)
Mixer, SubtitlesAudio levels and buses (Audio); captions (Captions)
Scopes, Nodes, CurvesColor tools (Color); Curves is also the keyframe graph
Export, JobsExport settings and the render queue (Export)
Markers, Auto-cut, Tracking, Planner, Moodboard, HistoryExtra tools, hidden until you open them (Advanced)

To open a panel that isn't showing, use any of these:

  • Click the + at the right end of a tab bar. It lists every panel that isn't on screen and adds the one you pick to that group.
  • Tick it in the Window menu. The less common ones are under Window ▸ More.
  • Press its shortcut, like Ctrl+1 for the Library (see shortcuts).
  • Type its name into the command palette (Ctrl+K).

Right-click a tab​

  • Maximise panel fills the window with that panel. Do it again (it now says Restore panel) to go back. Double-clicking a tab does the same, and so does ` (the key left of 1) with the mouse over a panel.
  • Undock moves the panel into its own window, for example onto a second monitor. Keyboard shortcuts keep working there. Close that window to dock the panel back where it was.
  • Close hides the panel. The Window menu brings it back.
  • Stay on this tab stops the group from switching away from this tab when you select something (see below). A pinned tab shows a pin.
  • Set Icon changes the tab's icon.

Moving and resizing panels​

Drag the gaps between panels to resize them.

Drag a tab to move its panel: nine drop squares appear over the panel under the pointer. Drop on the middle one to add it as a tab there, or on an outer one to split the space in that direction. Ctrl+Z undoes a move. Once you like your layout, Window ▸ Layout ▸ Lock Panels stops a stray drag from moving anything (tabs still switch, and the gaps still resize).

Undocked windows open where you last left them, at the same size.

Saving layouts​

Window ▸ Layout also has Save Profile…, Load Profile, Export Profile to File… and Import Profile from File… (a .sedit-layout file), to keep arrangements you like, switch between them on any page, or share them.

Panels that follow your selection​

When you select something, the group that edits it comes to the front: a video or text clip shows the Inspector, an audio clip the Mixer, a transition Transitions, a subtitle Subtitles. If you'd rather have panels stay put, turn off Settings ▸ General ▸ Switch panel tabs to follow the selection, or pin a single tab with Stay on this tab. With it off, the tab that would have switched glows briefly instead.

Every menu item shows its shortcut, and right-clicking one lets you give it a different icon.

Find any command: Ctrl+K​

Press Ctrl+K and start typing. The command palette searches every command, every panel ("Show Mixer"), and your scripts. Enter runs the highlighted row; greyed-out rows say why they can't run right now. With nothing typed, your recent commands come first.

Some commands live only here, for example Restore Autosave…, Fast Review and Trim View in Preview.

See every shortcut: F1​

F1 opens Keyboard Shortcuts: every command by group with its key, the keys that can't be changed, and all the timeline's mouse gestures. Type in its search box to filter. The same list is on the keyboard shortcuts page.

Settings​

File ▸ Settings… (Ctrl+Comma) has six tabs:

  • General: theme, where FFmpeg and yt-dlp are, autosave, snapping, the "follow the selection" and home-card switches, the Explorer right-click entry, fonts, and the MCP server for AI co-editing.
  • Performance: GPU preview, preview quality, the playback cache, proxies, movie mode.
  • Capture: screen recording and voiceover inputs.
  • Export: default encoder, quality and speed preset.
  • Hotkeys: rebind any command. Click Rebind, press the keys (Esc cancels, Backspace unbinds). A Keymap preset switches to Premiere, Resolve or Avid style keys, and the keyboard map shows what's taken.
  • Appearance: Cozy (rounded) or Sharp look, 25+ built-in themes, your own colours, clip colours, a background image, and icons. Themes can be exported and imported as .sedit-theme files.
