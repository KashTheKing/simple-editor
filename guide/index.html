Getting started

Simple Editor is a video editor for Windows that comes as one small .exe. Every page of this guide starts with a screenshot of the real app, taken by a script, so what you see here is what you get.

  • New to video editing? Read the pages in order: the interface, then importing, the viewer and the timeline. That's enough to cut a video and export it.
  • Coming from Premiere, Resolve or CapCut? Skim Coming from another editor below, then keep the keyboard shortcuts and the right-click reference open.

Download and run​

  1. Download simple-editor.exe from the latest release.
  2. Put it in any folder and double-click it. There is no installer.
  3. Install FFmpeg, which Simple Editor uses to export and to read some formats: winget install Gyan.FFmpeg (or choco install ffmpeg). Playback works without it, export doesn't. If FFmpeg isn't on your PATH, put ffmpeg.exe and ffprobe.exe next to simple-editor.exe, or point Settings ▸ General ▸ ffmpeg folder at them.

The first launch​

The first time you start the app, a Welcome to Simple Editor window walks you through three short cards. Use Next and Back, then Finish:

  1. ffmpeg tells you whether FFmpeg was found.
  2. Twelve keys to know: play, shuttle, mark In and Out, split, trim, the command palette, undo and save. Show all… opens the full shortcut list.
  3. Start with a format: keep 1920×1080, or pick YouTube, YouTube Shorts, TikTok, Instagram Reels and so on. The checkbox below adds Edit with Simple Editor to Explorer's right-click menu for videos.

You can bring the window back any time with Help ▸ Show Welcome Again.

Open or import your media​

An empty project shows a small home card. Its buttons do the same as the menus:

  • Open… (Ctrl+O, File ▸ Open Video / Media…) opens a video, or a .sedit project. Opening a video starts a new project built around it.
  • Import media… (Ctrl+I) adds files to the Library without touching the timeline.
  • Blank project starts an empty 1920×1080, 60 fps project; a button under Start from a format starts one in that format instead. Recent projects lists your last five.
  • The × hides the card for this session.

You can also drag files from Explorer onto the window. Where you drop them matters:

Drop onWhat happens
The timelineThe clip is placed where you let go (hold Ctrl to insert, Alt to overwrite)
The PreviewThe clip is placed at the playhead, on a free video track
Anywhere elseThe file is imported into the Library

Simple Editor reads video (mp4, mov, mkv, webm, avi, m4v, wmv, ts, m2ts, mts, flv, 3gp, mpg, mpeg, gif), audio (mp3, wav, m4a, aac, flac, ogg, opus, wma) and images (png, jpg, jpeg, bmp, webp, tif, tiff).

Opening a video from Explorer

Right-click a video in Explorer ▸ Edit with Simple Editor (on Windows 11 it's under Show more options). A video opened this way starts playing in a full-window player. Press Esc to get to the editor.

Save your work​

  1. File ▸ Save Project As… (Ctrl+Shift+S) saves the project as a .sedit file. A * in the window title means there are unsaved changes.
  2. After that, File ▸ Save (Ctrl+S) saves to the same file.
Ctrl+S on an opened video

If you opened a single video and haven't saved a project yet, Ctrl+S offers to overwrite the original video with your edit. It asks first. Use Save Project As… if you want to keep the original.

You don't lose work if the app or Windows crashes:

  • Autosave writes a copy of your project every 30 seconds while it has unsaved changes. Change the interval in Settings ▸ General ▸ Autosave interval (0 turns it off).
  • After a crash, the next start asks Recover unsaved project?. Click Yes to load it.
  • Older autosaves are listed by Restore Autosave… in the command palette (Ctrl+K).
  • Almost everything can be undone with Ctrl+Z and redone with Ctrl+Shift+Z (or Ctrl+Y). Deleting something shows a message with an Undo button too.

Coming from another editor​

Most of what you know carries over. The main differences:

You know it asIn Simple Editor
Resolve's pagesThe Media / Cut / Edit / Color / Audio / Export buttons in the middle of the menu bar (Alt+1–Alt+6)
Razor / add editSplit at Playhead Ctrl+B, or the Blade tool C
Ripple deleteShift+Delete
Search every commandThe command palette, Ctrl+K
Your old keyboard layoutSettings ▸ Hotkeys ▸ Keymap preset: Premiere, Resolve or Avid
Source monitor, Insert / OverwriteThe Source tab next to Preview; Shift+V inserts, B overwrites
Compound clip / nestClip ▸ Nest Selection into a New Sequence (Alt+N)
Adjustment layerClip ▸ Add ▸ Add Adjustment Layer (Ctrl+Alt+L)
Rate stretchThe Rate stretch tool R, or Shift+drag a clip edge

Two defaults that catch people out: B is Overwrite, not the razor, and Ctrl+K is the command palette, not "add edit". The Premiere preset moves split back to Ctrl+K.
