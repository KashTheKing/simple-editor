Simple Editor

A tiny, blazingly-fast, free and open-source video editing software for every editing-need. Written in 100% Rust.

Download for Windows only ~10 MB! Join the Discord
Rust docs

Simple Editor is a tiny, fast video trimmer/editor for Windows. Open a video, watch it, cut it, add music/SFX, overlay images/video/text, keyframe things — and save over the original or export to any format. It's built in Rust with egui, ships as a single ~10 MB exe, starts instantly, and stays light on CPU, GPU and memory.

Features

  • Decoding: Windows Media Foundation (native system codecs, no extra DLLs, instant seeks); ffmpeg.exe as a universal fallback (and for images).
  • Export: ffmpeg.exe — any container/codec by extension (mp4, mov, mkv, webm, avi, gif, mp3, wav…), hardware encoders (NVENC/QSV/AMF), and Fast Lossless Cut for instant, keyframe-accurate trims.
  • Timeline: multiple video + audio tracks, per-track mute/solo, linked audio/video clips, split, ripple delete, trim by dragging edges, snapping, waveforms, keyframe diamonds, zoom/pan.
  • Inspector: position / scale / rotation / opacity / volume with keyframes, 13 blend modes, a full text tool.
  • Import URL…: paste a link and yt-dlp downloads it straight into the library.
  • GPU effects: blur, motion blur, VHS, chroma key, curves/levels/hue, edge glow, threshold, 3D plane, JPEG crush, blob tracking, REC dot, and your own GLSL shader — with automatic CPU fallback.
  • Tools, shapes and masks: rectangle/ellipse/triangle/polygon/star/line/arrow, freehand draw, vector shape clips, adjustment layers, masks on clips or effects.
  • Node editor: a clip's effect stack as a graph when a straight stack isn't enough.
  • Mixer: audio buses with EQ, high/low-pass, reverb, echo, distortion, compressor, noise gate, per-track and per-clip routing.
  • Markers, Copy/Paste Attributes, and Export Frame (PNG/JPG/WebP at any scale).
  • Screen recording and voiceover through ffmpeg, including recording while the editor is in the background.
  • Import timelines from Premiere / DaVinci Resolve, EDL and .prproj, with an honest report of what didn't survive.
  • Theme: follows Windows dark/light + accent colour.
  • Scripting: sandboxed Luau scripts drive the same tool catalogue the MCP server exposes.
  • MCP server for AI co-editing: the whole timeline, effects, masks, nodes, markers, buses, shapes and more as tools.
  • Plain JSON project format (.sedit), Explorer context menu integration, and every hotkey rebindable in Settings.
