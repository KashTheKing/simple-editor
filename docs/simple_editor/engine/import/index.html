simple_editor::engine

Module import

Source
Expand description

Import timelines from other editors, with an honest per-item report.

Supported: Final Cut Pro 7 XML (.xml - what Premiere Pro exports and DaVinci Resolve reads/writes), EDL (CMX 3600) and uncompressed Premiere .prproj (the same XML reader). A real .prproj is gzip-wrapped and there is no inflate in-tree, so those are accepted by the picker only to answer with the “export FCP7 XML instead” note below. Anything the reader cannot map (unknown effects, missing media, speed ramps, colour pages) becomes an Issue instead of failing the import.

MAX_XML_DEPTH 🔒
Maximum element nesting. El drops recursively and find_all recurses, so an adversarial file of 100k nested tags would overflow the (UI-thread) stack — which no catch_unwind can catch. Real FCP7/EDL exports are under 20 deep.

PROBING 🔒
Paths with a probe still out. By path rather than asset id: a probe outlives the project that started it, and paths are what the library has to hand. ponytail: linear scan under one lock — an import batch is a handful of files, not a thousand.
