vec3 fx_ycc(vec3 c) {
    return vec3(dot(c, vec3(0.299, 0.587, 0.114)),
                dot(c, vec3(-0.168736, -0.331264, 0.5)) + 0.5,
                dot(c, vec3(0.5, -0.418688, -0.081312)) + 0.5);
}

}

JPEG-ish: the block DC (4 taps) is quantised coarsely, the AC residual more coarsely still, and the chroma optionally read from a 2x2 grid (4:2:0). This is an approximation - there is no DCT here, but the visible artefacts (blocking, colour smear, banding) track Quality the same way.
