Overlay for the colour tracker: tints everything within Tolerance of the target and draws a crosshair at the centroid.

Extra uniform gpu.rs must bind: vec3 u_blob = (cx, cy, area) from engine::effects::track, cx/cy in 0..1 layer coordinates and area <= 0 when nothing was found (then only the mask shows).
