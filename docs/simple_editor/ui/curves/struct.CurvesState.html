Fields§

§active: usize

Index of the active property in the panel’s property list.

§target_bus: Option<u64>

The bus whose automation the pane is editing; None = follow the clip selection.

§seen_mixer_bus: Option<u64>

Last mixer selection this pane reacted to, so a bus picked there switches the target once and the user can still choose something else here afterwards.

§list_w: f32

Width of the property list in points (drag the splitter; remembered across frames).

§hidden: Vec<usize>

Hidden curves (property indices).

§scroll_x: f64

Time zoom/pan of the graph (seconds at the left edge, px per second; 0 = fit the clip).

§zoom: f32§y_zoom: f64

Value-axis view on top of each property’s auto range: 1 = the whole range, pan in range units.

§y_pan: f64§selected: Vec<(usize, usize)>

Selected keys as (property index, key index).

§graph: Rect

Last frame’s graph rect / effective px-per-second / active y scale (hit-testing + tests).

§pps: f32§y_lo: f64§y_hi: f64§drag: Option<Drag>§drag_y: Vec<(usize, (f64, f64))>

y scales latched per property for the running key/handle drag: the per-frame auto scale is derived from the very values the drag writes, so a live scale would feed the dragged value back into itself.

§drag_keys: Vec<(usize, Vec<Keyframe>, Vec<usize>)>

The selected keys as they were when the drag started, per property: (prop, keys, selected indices). The whole gesture is re-derived from this snapshot, so nothing accumulates rounding.

§drag_from: Option<Pos2>

Pointer position at drag start — the group moves by the delta from it.

§band: Option<Pos2>

Rubber-band press origin while a band select is in progress.

§clipboard: Vec<(usize, Keyframe)>

Copied keys as (property, key) with times relative to the earliest of them.

§preset_name: String§preset_sel: usize§motion_sel: usize§menu_key: Option<(usize, usize)>

Key under the open context menu.
