# Hand-off: parity-effects (`claude/parity-effects`, new from origin/develop)

Section "parity-effects" of `plans/cloud-handoff.md` (item 9 of `plans/shotcut-comparison.md`).
The full filter-by-filter audit is `plans/effects-parity-audit.md`.

## Done
- **Blend modes** (`model::BlendMode`, `engine::blend`, `shaders::BLEND`): Exclusion, Saturate, Hue, Saturation,
  Color, Luminosity, appended after Color Burn so older modes keep their GLSL `int`. The CPU path gained
  `blend_pixel` (whole-pixel, W3C non-separable formulas); `composite_row` uses it for those five. GLSL mirrors it.
  Saturate is Cairo's operator read against the opaque canvas's brightness (adds the layer only as far as no
  channel clips); Cairo's literal form is a no-op on an opaque canvas. `BlendMode::desc()` feeds tooltips in the
  Inspector's Blend combo and the node editor.
- **Eyedropper white balance**: `PickTarget::WhiteBalance`; a **White Balance** button in the Color section
  (`color_ui.rs`) arms it (`PENDING_EYEDROP` now carries the target); the click scales Primaries Gain R/G/B by
  mean / channel (`tools_monitor::white_balance_gains`; dark or clipped picks are ignored). `color.pick` takes
  `target: "white_balance"`. Removed the dead "Eyedropper ... not wired yet" toast in `actions.rs::poll_panels`
  (FRAME_HOOKS drain the slot first, so it never fired; if it had, it would have eaten the pick).
- **Custom gradient wipe**: `library/transitions/gradient-wipe.glsl` (8 built-in patterns, softness, invert).
  The picked image is a `// @image <path>` header line in the transition's own shader copy
  (`shaderlib::with_image` / `ShaderMeta::image`), so no `Transition` struct change. `transition_shader` declares
  `u_gradient` / `u_has_gradient`; `GpuRenderer::wipe_texture` binds it on unit 7. `engine::wipe_image` decodes
  the picture once per path on a worker thread (640x360); the preview never waits (built-in pattern until it is
  ready), `render_frame` / `export_target` set `wait_for_wipes` and block (10 s cap). `transition_key` ignores the
  `@image` line, so picking an image never recompiles. Inspector: **Gradient Image** row for any shader using
  `u_gradient`. MCP: `transition.set_shader` gains `image`.
- **26 library effects**: wave, vertigo, nervous, choppy, alpha-strobe, chroma-hold, key-spill, circle-crop,
  deband, dither, elastic-scale, posterize, sepia, scan-lines, vibrance, unpremultiply, technicolor,
  film-projector, rutt-etra, smart-blur, spot-remover, color-gradient, grid-lines, alpha-view, alpha-adjust,
  emboss. `library/index.json` rows added (generated by a Python port of `entry_of`; existing rows came out
  byte-identical, so the port matches).
- Docs: CHANGELOG (Unreleased), `docs/customizing.md`, `library/README.md`, `website/docs/{color,effects,inspector}.mdx`.

## Verified here (Linux container)
- `cargo check --target x86_64-pc-windows-gnu --all-targets`: passes. `cargo test --target x86_64-pc-windows-gnu --no-run`: test code compiles.
- The bin can't build for Linux (winit), and Wine crashes in this sandbox, so unit tests ran in a scratch crate
  that compiles `engine/blend.rs`, `engine/shaderlib.rs`, `engine/wipe_image.rs` and `white_balance_gains`
  against small shims: 10/10 pass (new: exclusion/saturate, HSL modes, composite HSL path, `@image` set/replace/
  remove, wipe cache, white balance) plus `shaderlib::lint` over every library shader.
- Every new shader and the composite program (new BLEND) compile with `glslangValidator`, assembled exactly like
  `shaders::user_shader` / `transition_shader`.
- A WebGL2 (SwiftShader) port of `library_shaders_compile_and_draw_on_the_real_driver` (same stand-in pictures,
  480x270, `u_scale`, times, `@needs previous` shifted frames, alpha-tag picture) passes for all 27 new files,
  and a contact sheet of them was checked by eye.

## Risks
- Thin margins in the real-driver "visible change" check (mean diff needs >= 0.5): smart-blur 0.58,
  spot-remover 0.59, alpha-adjust 0.59, deband 0.75 under SwiftShader. A real driver could land just under; nudge
  the default (radius / box size / grow) if one fails.
- `wait_for_wipes` blocks the thread `GpuRenderer` runs on (the UI thread) until the gradient image is decoded,
  10 s at most, only on an export frame. It is normally decoded long before: picking it warms the cache and the
  preview asks for it every frame. The case that waits is opening a project and exporting at once (one decode,
  typically well under a second).
- The CPU compositor and XML/EDL export cross-fade a gradient wipe, like every shader transition.
- Not built (needs compositor work, not shaders): drop shadow outside an opaque clip, Pillar Echo. Corner pin,
  lens correction, denoise bakes, 360, generators and timer are other sections.
