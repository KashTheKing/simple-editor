---
title: More than one screen
description: Spread the editor over 2 or 3 monitors, move panels between windows, and how each page remembers it.
---

With more than one monitor, Simple Editor can give the timeline (and the preview) a screen of its own.

## Turn it on

When the editor sees a second monitor (the first time it starts, or when you plug one in) it asks
**Use 2-screen mode?** (or 3-screen with three monitors), with a small picture of each arrangement:

| Choice | What goes where |
|---|---|
| **Use 2 screens** | the Preview and the small tools (Inspector, Library, Gallery…) on the main screen, the Timeline full size on the second |
| **Use 3 screens** | the tools, the Timeline and the Preview each on their own screen |
| **Keep one screen** | everything in one window, as before |

You can change it any time from **Window ▸ Screens…** or **Settings ▸ General ▸ Layout ▸ Screens…**.
The question is not asked again for the same monitors; it comes back when you connect more.

## Move panels between screens

- Right-click a tab ▸ **Move to window ▸ Main window / Screen 2 / Screen 3**.
- Or **Window ▸ Move to window ▸** *panel* ▸ the screen.
- Or drag a tab out of the main window and let go over another monitor: it joins that screen's window. Let
  go beside the window on the same monitor and it opens in a window of its own (like **Undock**).

Inside each screen's window, panels dock, tab and split like in the main one. Closing a screen's window puts
its panels back in the main window.

## Each page remembers its screens

Every page keeps one arrangement **for each screen count**: change the Edit page's 2-screen layout and its
one-screen layout is untouched; switch back to 2 screens and your changes are there again. **Window ▸ Layout ▸
Reset Page Layout** goes back to the page's built-in arrangement for the screens in use.

Each window reopens on the monitor it was on. If that monitor is missing, its panels fold back into the main
window, so nothing is ever lost off-screen.
