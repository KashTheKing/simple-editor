![The Edit page](/img/tutorial/edit-page.png)

The window has two parts: the **top bar**, and the **panels** below it. Each panel sits in a group with
tabs along its top.

The top bar is also the window's title bar: the app icon and the menus on the left, the **page buttons** in
the middle, then **Performance**, **Jobs** and **Quick Export** and the minimise / maximise / close buttons on
the right. Drag it to move the window, double-click it to maximise. Every window of the app (popped-out panels,
screen windows, Screen Recording, the [media player](media-player.mdx)) has the same bar. A window that isn't
maximised has rounded corners and a thin outline (square with the **Sharp** look).

## Pages

Pages are ready-made arrangements of panels for one kind of work, in the same order as Resolve's pages.
Switch with the buttons in the middle of the top bar, **Window ▸ Pages**, <kbd>Alt+1</kbd>–<kbd>Alt+6</kbd>, or
<kbd>Ctrl+E</kbd> for Export.

| Page | Key | What's on it |
|---|---|---|
| **Media** | <kbd>Alt+1</kbd> | Library · Source · Inspector, full height. Bringing in, sorting and watching media. |
| **Plan** | <kbd>Alt+2</kbd> | Planner / Moodboard / Markers / Subtitles / Voiceover / Transcript / Clips · Source / Preview · Inspector on top; a small Library / Media Browser beside Timeline / Beat Aligner below. Planning and rough assembly. (It was called Cut.) |
| **Edit** | <kbd>Alt+3</kbd> | Library (with the Gallery: Effects, Transitions, Looks…) · Source / Preview · Inspector / Clips, the Timeline below. The page the app opens on. |
| **Animate** | <kbd>Alt+4</kbd> | Gallery · Preview · Inspector over a thin Timeline and the [Animator](animator.mdx). |
| **Color** | <kbd>Alt+5</kbd> | A big Preview beside Inspector / Nodes / Gallery, Clips / Timeline across the middle, then Color Wheels · Curves · Scopes. |
| **Audio** | <kbd>Alt+6</kbd> | Library / Media Browser / Gallery · Preview · Voiceover / Transcript / Subtitles · Inspector on top; Timeline / Beat Aligner beside the Mixer below. |
| **Export** | <kbd>Ctrl+E</kbd> | Export settings (with the project settings) · Preview · Jobs / Performance, with the Timeline below. |

### Pages or One window

Prefer one arrangement for everything? **Window ▸ Layout ▸ One Window** drops the page buttons: one workspace
with every panel, where each panel stays where you dock it and the rest are in the Window menu and
<kbd>Ctrl+P</kbd>. **Window ▸ Layout ▸ Pages** brings the pages back, with their layouts as you left them. The
first-run setup asks which you want.

Every page remembers its own arrangement. Changing the Color page never touches the Edit page.

**Make an arrangement the page's default** with **Window ▸ Layout ▸ Save as This Page's Default**. Then:

- **Reset Page Layout** (in **Window ▸ Layout**, or right-click the page's button) goes back to your
  default, or to the built-in one if you haven't saved one. <kbd>Ctrl+Z</kbd> undoes it.
- **Reset to Built-in Layout** goes back to the page as it came with the app.

## Panels

| Panel | What it's for |
|---|---|
| **Library** | Your imported media, sequences and folders ([Library](library.mdx)) |
| **Source** | Watch a clip from the Library and mark the part you want ([Source monitor](library.mdx#the-source-monitor)) |
| **Preview** | The program monitor: what your edit looks like ([Viewer](viewer.mdx)) |
| **Timeline** | Where you arrange and cut clips ([Timeline](timeline.mdx)) |
| **Inspector** | Settings of whatever is selected ([Inspector](inspector.mdx)) |
| **Effects**, **Transitions**, **Gallery** | Things to add to clips ([Effects, transitions & titles](effects.mdx)) |
| **Mixer**, **Subtitles** | Audio levels and buses ([Audio](audio.mdx)); captions ([Captions](captions.mdx)) |
| **Scopes**, **Nodes**, **Curves** | Color tools ([Color](color.mdx)); Curves is also the keyframe graph |
| **Export**, **Jobs** | Export settings and the render queue ([Export](export.mdx)) |
| **Markers**, **Auto-cut**, **Tracking**, **Planner**, **Moodboard**, **History** | Extra tools, hidden until you open them ([Advanced](advanced.mdx)) |

**To open a panel that isn't showing**, use any of these:

- Click the **+** at the right end of a tab bar. It lists every panel that isn't on screen and adds the
  one you pick to that group.
- Tick it in the **Window** menu. The less common ones are under **Window ▸ More**.
- Press its shortcut, like <kbd>Ctrl+1</kbd> for the Library (see [shortcuts](shortcuts.md#panels--pages)).
- Type its name into the command palette (<kbd>Ctrl+P</kbd>).

### Right-click a tab

![Right-click a tab](/img/tutorial/tab-menu.png)

- **Maximise panel** fills the window with that panel. Do it again (it now says **Restore panel**) to
  go back. Double-clicking a tab does the same, and so does <kbd>`</kbd> (the key left of 1) with the
  mouse over a panel.
- **Undock** moves the panel into its own window, for example onto a second monitor. Keyboard
  shortcuts keep working there. Close that window to dock the panel back where it was.
- **Close** hides the panel. The Window menu brings it back.
- **Stay on this tab** stops the group from switching away from this tab when you select something (see
  below). A pinned tab shows a pin.
- **Set Icon** changes the tab's icon.

### Moving and resizing panels

Drag the gaps between panels to resize them.

**Drag a tab** to move its panel: nine drop squares appear over the panel under the pointer. Drop on the
middle one to add it as a tab there, or on an outer one to split the space in that direction.
<kbd>Ctrl+Z</kbd> undoes a move. Once you like your layout, **Window ▸ Layout ▸ Lock Panels** stops a stray
drag from moving anything (tabs still switch, and the gaps still resize).

Undocked windows open where you last left them, at the same size.

With more than one monitor, a tab's right-click ▸ **Move to window** sends a panel to another screen's window
(see [More than one screen](screens.mdx)).

### Saving layouts

**Window ▸ Layout** also has **Save Profile…**, **Load Profile**, **Export Profile to File…** and
**Import Profile from File…** (a `.sedit-layout` file), to keep arrangements you like, switch between
them on any page, or share them.

![The Window menu with Layout open](/img/tutorial/window-menu.png)

### Panels that follow your selection

When you select something, the group that edits it comes to the front: a video or text clip shows the
**Inspector**, an audio clip the **Mixer**, a transition the **Inspector** too, a subtitle **Subtitles**. If
you'd rather have panels stay put, turn off **Settings ▸ General ▸ Switch panel tabs to follow the
selection**, or pin a single tab with **Stay on this tab**. With it off, the tab that would have
switched glows briefly instead.

## The top bar's buttons

- **Performance** (the chart) opens the Performance panel, which shows how fast playback and the app are running.
- **Jobs** shows exports, proxies and other background work; the number is how many are running.
- **Quick Export** saves the timeline in one step: pick a file name and type (MP4, MOV, MKV, WebM, GIF, WAV,
  MP3) and it exports with your current export settings, then opens the file in your media player (see
  [Export](export.mdx#quick-export)).

## Messages

Short messages (toasts) appear at the bottom right and fade after a few seconds. Some have buttons: a deleted
clip's **Undo**, and for a saved screenshot or a finished export **Open**, **Open Folder** and **Add to
Project**.

Every menu item shows its shortcut, and right-clicking one lets you give it a different icon.

## Go to anything: Ctrl+P

![The command palette](/img/tutorial/palette.png)

Press <kbd>Ctrl+P</kbd> (<kbd>Ctrl+K</kbd> also works unless you gave it to something else) and start
typing. What the box does depends on the first character:

- **Plain text: go to.** Clips on any timeline (also inside nested sequences), timelines, media and bins
  in the Library, markers and comments, pages, panels and Gallery cards, grouped by type with the track
  and time, or the folder, in grey. <kbd>Enter</kbd> goes there: the playhead jumps to a clip and selects
  it, a timeline opens, media is shown and selected in the Library. <kbd>Alt+Enter</kbd> adds media at
  the playhead, or applies a Gallery card. With nothing typed, what you went to last comes first.
- **`>`: commands.** Every command with its shortcut, every panel ("Show Mixer"), your scripts and the
  on/off settings. Greyed-out rows say why they can't run right now.
- **`/`: the assistant.** `/ask <message>` sends a message; `/<skill>` runs a skill (the list shows
  every installed skill with its description as you type).

<kbd>Tab</kbd> and the arrow keys move through the results, <kbd>Esc</kbd> closes it.

Some commands live only here, for example **Restore Autosave…**, **Fast Review** and **Trim View in
Preview**.

## See every shortcut: F1

![The keyboard shortcuts window](/img/tutorial/cheatsheet.png)

<kbd>F1</kbd> opens **Keyboard Shortcuts**: every command by group with its key, the keys that can't
be changed, and all the timeline's mouse gestures. Type in its search box to filter. The same list is
on the [keyboard shortcuts](shortcuts.md) page.

## Settings

![Settings, Hotkeys tab](/img/tutorial/settings-hotkeys.png)

**File ▸ Settings…** (<kbd>Ctrl+Comma</kbd>) has ten tabs:

- **General**: theme, where FFmpeg and yt-dlp are, autosave, the cache budget and **Cache folder**, the
  **Web browser** links and the page-snapshot steps use, snapping, the "follow the selection" switch, **Start screen** (the home card; its **Don't show again**
  turns this off), **Ask to match the project to imported videos**, the Explorer right-click entry, fonts, and the MCP server for AI co-editing.

  **Cache folder** shows where renders, pre-renders, proxies, waveform peaks and downloaded models are kept,
  how much they use and the drive's free space. **Browse…** picks another folder (on a bigger or faster
  drive, say), then **Move existing cache** moves the files there in the background (a row in Jobs; a file
  still being written stays behind) or **Start fresh** leaves the old folder (tick *and delete the old
  folder* to remove it). The new folder is used at once. **Reset to default** goes back to
  `%LOCALAPPDATA%\SimpleEditor\cache`.

  **Web browser** is **Default** (the Windows default browser) or any browser installed, or **Other…** for
  a program of your own.
- **Performance**: GPU preview, preview quality, the playback cache, proxies, movie mode.
- **Capture**: screen recording and voiceover inputs.
- **Export**: default encoder, quality and speed preset.
- **Hotkeys**: rebind any command. Click **Rebind**, press the keys (<kbd>Esc</kbd> cancels,
  <kbd>Backspace</kbd> unbinds). A **Keymap preset** switches to Premiere, Resolve or Avid style keys,
  and the keyboard map shows what's taken.
- **Assistant**: the agent, model, API key, Guard and voice (see [Assistant](assistant.mdx)).
- **Social**: the account the social-media guides show (handle, name, picture, caption, sample comments) ([Social guides](social-guides.mdx)).
- **Permissions**: every MCP tool as Allow, Ask or Block ([Permissions](assistant.mdx#permissions)).
- **Metadata**: metadata presets for exports and the media player ([Media player](media-player.mdx#metadata)).
- **Appearance**: Cozy (rounded) or Sharp look, 25+ built-in themes, your own colours, clip colours, a
  background image, and icons. Themes can be exported and imported as `.sedit-theme` files.
  Built in: Premiere Pro, DaVinci Resolve and CapCut, each Dark and Light (their colours and feel only).
  **Import theme** also accepts other editors' settings, mapped as closely as the file allows: Premiere Pro
  preferences give only a UI brightness and a highlight colour (brightness sets the greys, the highlight becomes
  the accent; clip colours and radii come from the built-in Premiere Pro theme); CapCut preferences give only
  dark/light; DaVinci Resolve keeps no theme file, so pick its built-in theme. Unreadable files show a message
  and change nothing. The key names are matched loosely because those formats are undocumented.
