![Simple Editor with a project open on the Edit page](/img/tutorial/edit-page.png)

Simple Editor is a video editor for Windows that comes as one small `.exe`. Every page of this guide
starts with a screenshot of the real app, taken by a script, so what you see here is what you get.

- **New to video editing?** Read the pages in order: the [interface](interface.mdx), then
  [importing](library.mdx), the [viewer](viewer.mdx) and the [timeline](timeline.mdx). That's enough to
  cut a video and [export](export.mdx) it.
- **Coming from Premiere, Resolve or CapCut?** Skim [Coming from another editor](#coming-from-another-editor)
  below, then keep the [keyboard shortcuts](shortcuts.md) and the [right-click reference](right-click.mdx)
  open.

## Download and run

The [latest release](https://github.com/KashTheKing/simple-editor/releases/latest) has two downloads:

- **`simple-editor-setup.exe`** (under 1 MB) installs Simple Editor for you only, with no administrator
  prompt, into `%LOCALAPPDATA%\Programs\Simple Editor`. It adds a Start menu shortcut (a desktop one if you
  tick it), opens `.sedit` projects, and can add **Edit with Simple Editor** to video files' right-click menu.
  If FFmpeg isn't on your PC it says so and installs it (ticked by default; the download is checked against
  its published checksum). Optional add-ons (yt-dlp, whisper.cpp, the fast HTML renderer, the AI enhancer)
  are a tick each. Later, `update.exe` in the same folder updates the app and keeps your settings, and
  **Settings ▸ Apps ▸ Simple Editor ▸ Uninstall** removes it (you choose whether to keep your preferences;
  your projects are never touched).
- **`simple-editor.exe`** is the portable app: put it in any folder and double-click it. Then install
  **FFmpeg**, which Simple Editor uses to export and to read some formats: `winget install Gyan.FFmpeg`
  (or `choco install ffmpeg`). Playback works without it, export doesn't. If FFmpeg isn't on your `PATH`,
  put `ffmpeg.exe` and `ffprobe.exe` next to `simple-editor.exe`, or point **Settings ▸ General ▸ ffmpeg
  folder** at them.

## The first launch

![The welcome window](/img/tutorial/welcome.png)

The first time you start the app, a **Welcome to Simple Editor** window walks you through a few short
cards. Use **Next** and **Back**, then **Finish**:

1. **Your workspace**: **Pages** (Media, Plan, Edit, Animate, Color, Audio and Export tabs in the top bar, each
   with its own layout) or **One window** (one workspace with every panel). **Window ▸ Layout** switches later.
2. **Screens**, only with more than one monitor: keep one screen or spread the editor over two or three
   ([More than one screen](screens.mdx)).
3. **ffmpeg** tells you whether FFmpeg was found.
4. **Twelve keys to know**: play, shuttle, mark In and Out, split, trim, the command palette, undo and
   save. **Show all…** opens the full shortcut list.
5. **Start with a format**: keep 1920×1080, or pick YouTube, YouTube Shorts, TikTok, Instagram Reels and
   so on. The checkbox below adds **Edit with Simple Editor** to Explorer's right-click menu for videos.

You can bring the window back any time with **Help ▸ Show Welcome Again**.

## The Home page

![The Home page](/img/tutorial/home-page.png)

The app opens on the **Home page**. It has two parts:

- **New**: a row of cards that each make a project and take you straight into the editor. The **+** card
  makes a blank 1920×1080, 60 fps project; the others are the formats (General Long Form, General Short Form,
  Square, YouTube, YouTube Shorts, TikTok, Instagram Reels, 4K UHD and the rest), with the size and frame rate
  under the name. The 9:16 short-form formats start with a **Max length** of 1:00. Formats you saved
  yourself (the [Inspector's](inspector.mdx) project **Presets**) come last.
- **Projects**: your recent projects, each with a picture from its timeline, its title and its folder.
  **Open** (or a double-click on the row) opens it, **Open Folder** shows the file in Explorer, and
  **Rename** renames the `.sedit` file in its folder: it won't take a name that's already there, or rename a
  project another Simple Editor window has open. A project whose file is gone is greyed out with **Remove**
  in place of Rename; right-click any row for **Remove from List**. **Open…** opens a project that isn't listed.

**File ▸ Quit to Project List**, the app icon at the top left or the house button in the top bar goes back to Home; it closes the project, asking
to save first if there are changes. **File ▸ New** (<kbd>Ctrl+N</kbd>) goes to Home too, where the cards are.
Click the house button again to go to the editor with a blank project.

Don't want a Home page? Turn off **Settings ▸ General ▸ Home page**: the app then opens on an empty
project with the small home card described below, and **File ▸ New** makes a blank project as before.

## Open or import your media

![The home card on an empty project](/img/tutorial/home.png)

With the Home page off, an empty project shows a small home card. Its buttons do the same as the menus:

- **Open…** (<kbd>Ctrl+O</kbd>, **File ▸ Open Video / Media…**) opens a video, or a `.sedit` project.
  Opening a video starts a new project built around it.
- **Import media…** (<kbd>Ctrl+I</kbd>) adds files to the [Library](library.mdx) without touching the
  timeline. **File ▸ Import ▸ Import Folder as Bin…** (or dropping a folder) links a whole folder as a bin, instantly.
- **Blank project** starts an empty 1920×1080, 60 fps project; a button under **Start from a format**
  starts one in that format instead. **Recent projects** lists your last five.
- The **×** hides the card for this session. **Don't show again** hides it for good; **Settings ▸ General ▸
  Start screen** brings it back.

You can also **drag files from Explorer** onto the window. Where you drop them matters:

| Drop on | What happens |
|---|---|
| The timeline | The clip is placed where you let go (hold <kbd>Ctrl</kbd> to insert, <kbd>Alt</kbd> to overwrite) |
| The Preview | The clip is placed at the playhead, on a free video track |
| Anywhere else | The file is imported into the Library |

Simple Editor reads video (mp4, mov, mkv, webm, avi, m4v, wmv, ts, m2ts, mts, flv, 3gp, mpg, mpeg,
gif), audio (mp3, wav, m4a, aac, flac, ogg, opus, wma) and images (png, jpg, jpeg, bmp, webp, tif,
tiff).

:::tip Opening a video from Explorer
Right-click a video in Explorer ▸ **Edit with Simple Editor** (on Windows 11 it's under **Show more
options**). A video or song opened this way plays in the [media player](media-player.mdx). Press <kbd>Esc</kbd>
to take it into the editor.
:::

## Save your work

1. **File ▸ Save Project As…** (<kbd>Ctrl+Shift+S</kbd>) saves the project as a `.sedit` file. A `*` in
   the window title means there are unsaved changes.
2. After that, **File ▸ Save** (<kbd>Ctrl+S</kbd>) saves to the same file.

:::caution Ctrl+S on an opened video
If you opened a single video and haven't saved a project yet, <kbd>Ctrl+S</kbd> offers to **overwrite
the original video** with your edit. It asks first. Use **Save Project As…** if you want to keep the
original.
:::

You don't lose work if the app or Windows crashes:

- **Autosave** writes a copy of your project every 30 seconds while it has unsaved changes. Change
  the interval in **Settings ▸ General ▸ Autosave interval** (0 turns it off).
- After a crash, the next start asks **Recover unsaved project?**. Click **Yes** to load it.
- Older autosaves are listed by **Restore Autosave…** in the command palette (<kbd>Ctrl+P</kbd>, then `>`).
- Almost everything can be undone with <kbd>Ctrl+Z</kbd> and redone with <kbd>Ctrl+Shift+Z</kbd>
  (or <kbd>Ctrl+Y</kbd>). Deleting something shows a message with an **Undo** button too.

## Coming from another editor

Most of what you know carries over. The main differences:

| You know it as | In Simple Editor |
|---|---|
| Resolve's pages | The **Media / Plan / Edit / Animate / Color / Audio / Export** buttons in the middle of the menu bar (<kbd>Alt+1</kbd>–<kbd>Alt+6</kbd>, <kbd>Ctrl+E</kbd>) |
| Razor / add edit | **Split at Playhead** <kbd>Ctrl+B</kbd>, or the **Blade** tool <kbd>C</kbd> |
| Ripple delete | <kbd>Shift+Delete</kbd> |
| Search every command | The **command palette**, <kbd>Ctrl+P</kbd> then `>` |
| Go to a clip, bin or marker by name | <kbd>Ctrl+P</kbd> and type its name |
| Your old keyboard layout | **Settings ▸ Hotkeys ▸ Keymap preset**: Premiere, Resolve or Avid |
| Source monitor, Insert / Overwrite | The **Source** tab next to Preview; <kbd>Shift+V</kbd> inserts, <kbd>B</kbd> overwrites |
| Compound clip / nest | **Clip ▸ Nest Selection into a New Sequence** (<kbd>Alt+N</kbd>) |
| Adjustment layer | **Clip ▸ Add ▸ Add Adjustment Layer** (<kbd>Ctrl+Alt+L</kbd>) |
| Rate stretch | The **Rate stretch** tool <kbd>R</kbd>, or <kbd>Shift</kbd>+drag a clip edge |

Two defaults that catch people out: <kbd>B</kbd> is **Overwrite**, not the razor, and
<kbd>Ctrl+K</kbd> opens the command palette (like <kbd>Ctrl+P</kbd>), not "add edit". The Premiere preset
gives <kbd>Ctrl+K</kbd> to split.
