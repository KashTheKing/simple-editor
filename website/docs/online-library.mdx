The **Gallery** can also list an online library, as part of its own tabs: **Effects**, **Transitions** and
**Luts** show the built-in cards, yours, what is already installed and the online items in one grid, and
**HTML**, **Icons** and **Skills** are tabs of their own. Nothing is bundled in the exe, and **nothing is
fetched until you ask**: a fresh install makes no network call at all.

- Each tab shows a small **Browse online library** button under the search box. Click it once: the list of
  free items (a small index, no pictures or files) is fetched, **Online** becomes a chip next to **All**,
  **Built-in**, **Mine** and **Installed**, and from then on the library is listed every time you open the
  Gallery. Until then the Gallery lists only the built-in cards, yours and what is installed.
- **Click an online card** (cloud mark) and just that one item downloads, with a progress bar on the card,
  then it is applied. After that it is on your PC and behaves like any other card. Nothing else is ever
  downloaded in bulk.
- The **⋯** menu of a tab has **Refresh the online catalogue**, **Turn the online library off** (what is
  installed stays) and **Use a folder as the library…**, which reads a local folder with an `index.json`
  instead: use it to try your own items or to work offline.
- What a project uses is stored **in the project**: send the project to a friend and it still looks the
  same. LUTs are copied into a folder beside the project file.
- Search covers the library's names, tags and descriptions once it is connected.

## What is in it

| Tab | What you get |
|---|---|
| Transitions | Shader transitions in the gl-transitions format |
| Effects | Shader effects with named controls, every control keyframeable |
| LUTs | 3D colour looks (`.cube`), also readable by Premiere and Resolve |
| HTML | [HTML layers and scenes](html-layers.mdx): titles, buttons, bubbles, end screens |
| Icons | SVG icons |
| Skills | Recipes for the [Assistant](assistant.mdx) |

## Add your own

Shaders are text files with a short header, so you can write them in the **Shader Editor** (which can
save to the library) or ask the [Assistant](assistant.mdx). The file formats and the rules for sharing an
item are in [`library/README.md`](https://github.com/KashTheKing/simple-editor/blob/main/library/README.md);
to contribute, open a pull request on GitHub.

## Skills

A skill is a Markdown file the Assistant follows when you type `/` and its name (for example
`/captions bold yellow`, `/lower-third`, `/shorts`). The **Skills** tab in the Assistant lists them with
Run, Edit and Duplicate. `/create-skill …` writes a new one for you. Your own skills live in
`%APPDATA%\SimpleEditor\skills`.
