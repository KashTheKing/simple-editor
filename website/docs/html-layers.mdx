An **HTML layer** is a clip made from HTML and CSS: a lower third, a subscribe button, a chat bubble, a whole
scene. It is drawn by the Microsoft Edge that comes with Windows, keeps its transparency, animates with
CSS, and is exported with the video. There is no JavaScript: scripts are removed.

## Add one

- **Add ▸ HTML Layer** (transparent, sits over video) or **Add ▸ HTML Scene** (full frame with its own
  background) gives you a starter you can change.
- **Add ▸ Import HTML File…**, or drop a `.html` or `.mhtml` file on the timeline. The clip is **linked** to the
  file: edit either side. Linked CSS and images are followed and render again when they change.
- The [online library](online-library.mdx) has ready-made layers (buttons, lower thirds, bubbles, end screens).

On the timeline an HTML clip shows a `</>` mark instead of a filmstrip.

## Edit it

Select the clip: the [Inspector](inspector.mdx) shows its **code** with syntax colours and completion.
**Fields** (the texts and colours a template exposes) are plain controls above it. Double-click the clip, or press
the pop-out button, to open the **HTML editor** in its own window: live preview, a scrub bar, and an
**Ask the assistant** box. **F11** makes it full screen. You can also open the file in your own code editor
and the clip follows.

Problems (a missing closing tag, something that is not allowed, such as a network address in a
template) show as a list under the code.

## Animate it

Motion is CSS: `@keyframes` and `animation`. The app sets the time of every animation per frame, so what
you write is what renders at any frame rate.

To animate a number from the timeline, declare a **parameter**:

```html
<meta name="se:param" content="progress | number | 0 | 0 | 100">
<style> .bar { width: calc(var(--progress) * 1%); } </style>
```

`progress` shows in the Inspector with a keyframe diamond, and your CSS reads it as `var(--progress)`.

## Web Page Snapshot

**Add ▸ Web Page Snapshot…** copies a real web page into your edit as HTML and CSS you can scroll, zoom and
animate. Pick a size (Phone, Short, Desktop or your own width) and one of two ways:

- **From a web address.** Paste the address. Simple Editor opens it in its own private page renderer, as a visitor
  who is not signed in, keeps the HTML and CSS, drops the scripts, and adds a linked clip. Pages that need a
  login, or fill themselves in with scripts, may come out empty.
- **From my browser.** For the page exactly as you see it (signed in, scrolled, a menu open). Install the tiny
  extension once: the window can **save the extension to a folder**, and shows the steps for your browser
  (open its extensions page, such as `chrome://extensions` or `edge://extensions`, turn on **Developer mode**,
  click **Load unpacked** and pick that folder). Then click the extension's button, or press **Alt+Shift+S**,
  on any page. The snapshot lands in your browser's download folder and appears in Simple Editor as a new clip
  within a couple of seconds. Nothing leaves your computer. The extension works in Chromium-based browsers
  (Chrome, Edge, Brave, Vivaldi, Opera, Arc…). Firefox cannot save a page as one file: there, press **Ctrl+S**,
  save as **Web Page, complete** and use **Import a saved page…**.

  Simple Editor uses your Windows default browser; pick another in **Settings ▸ General ▸ Web browser**.

  No extension? Save the page as a single file (`.mhtml`) and drop it on the timeline.

## Fake mouse

Select an HTML clip and open **Mouse** in the Inspector. Tick **Fake mouse**, then keyframe **X** and **Y** (page
pixels from the top-left of the visible page) and **Pressed**. **Click here** adds a press and a release at the
playhead. The page reacts like a real one: `:hover` and `:active` styles and the CSS transitions they start
play, frame-exact. Links go nowhere. The mouse reaches the top screenful of the page; scroll the page first
for lower parts.

## For AI agents

Everything above is also available over MCP: `html.create`, `html.get`, `html.set` (source, fields,
parameters), `html.import`, `html.link`, `html.snapshot`, `html.render` and `html.check` (one rendered frame
as an image). See [Scripting & MCP](scripting.mdx).

## Your project's pictures and videos, by name

Write a plain file name and the layer uses the project's file of that name: `<img src="logo.png">`,
`<video src="clip.mp4">`, `background: url("bg.jpg")`. The app looks in the project's folder first,
then at the media in the project (any upper / lower case), and for a name without an extension
(`logo`) takes the one file called that. If two files share the name, the one in the project folder
wins (else the newest), and you get a warning; a name it cannot find shows as **missing: logo.png**
under the source in the Inspector. Change the file on disk and the layer updates.

A video plays muted. On the timeline and in the export it is exactly in step with the layer; in the
live preview it simply plays. Animated GIFs play in the preview but are not frame-exact on the
timeline: use a video when timing matters.

## The fast renderer

HTML layers can be drawn by a small built-in renderer instead of Microsoft Edge. It is a separate 11 MB
program (`se-html`), so the editor itself stays small: install it once with the **Install** button the
Inspector shows (nothing downloads before you press it). It uses about 25 MB of memory instead of
Edge's 700 MB, draws a frame in milliseconds, and never opens a browser.

Inspector > HTML > **Renderer**:

- **Auto** (default): the fast renderer when it is installed and the layer only uses CSS it can draw,
  otherwise Edge. The line under the setting says which one drew the layer and, when it is Edge, why,
  for example "uses a blend mode (mix-blend-mode): rendering with Edge".
- **Fast (built-in)**: always the fast renderer, even for a layer Auto would send to Edge (it may then
  look different).
- **Edge**: always Edge.

What it cannot draw (Auto uses Edge for these): colour filters (`hue-rotate`, `saturate`, `brightness`,
`contrast`, `grayscale`, `sepia`, `invert`, `opacity()`), `mix-blend-mode` and `background-blend-mode`,
`position: sticky`, 3D transforms, CSS counters, vertical writing, and an inline SVG whose parts are
animated by the page's CSS or styled with a selector it cannot match (`:hover`, `[attr]`, `+`, `~`).
Everything else is drawn as in Edge, including `backdrop-filter`, `-webkit-text-stroke`, `@property`,
`text-shadow`, `text-overflow: ellipsis`, `text-wrap: balance`, justified text, and an inline SVG styled by
the page's own CSS (`.icon path { fill: var(--accent) }`: the rules are written onto the SVG's parts before it
is drawn). If the renderer fails on a layer (a crash, a hang) the layer is drawn by Edge instead; a crash
keeps it on Edge until the renderer is updated or the app restarts, a hang is tried once more first.

Two things stay with Edge: **Web Page Snapshot** (the page runs its scripts once, in a private Edge,
before it is saved) and any layer you set to Edge. Everything after the snapshot is drawn by the fast
renderer. `html.renderer` and `html.helper` do the same over MCP.

## The live preview

The Inspector's **Preview** and the HTML editor show the page itself, running: a field, a parameter or a
line of code you change shows at once, while the picture on the timeline is rendered frame by frame in
the background (a still of it shows within a moment).

Each preview has its own small player, separate from the timeline: a time bar you click or drag, play /
pause, previous / next frame (at the project frame rate), start and end, loop, and the time as timecode
and frame number. Picking a time holds that frame (exactly what the timeline renders there); play runs
the animation live from there, and keeps its place when you change a field. **Follow playhead** makes the
preview show the moment under the timeline playhead. Click the picture, then use Space, Left / Right and
Home / End.

## Fields the Inspector shows

Templates declare their editable values in the head (see the library format). Besides text, colour,
number and image there are **font** (a list of your installed fonts and the app's own; hover a name to
see the layer in it), **select** (named choices such as sharp / rounded / pill corners), **toggle** (shadow
on / off), **range**, **radius** and **size** sliders, **shadow** and **outline** (a size and a colour).
The library's templates come with a font, a corner radius, a shadow switch and an outline where they
have them, set to their original look.

## How long layers render

An HTML layer is rendered frame by frame at your project's frame rate (60 fps project: 60 frames a
second of layer). A long one shows up in steps, so you never wait for the whole thing before you can
work:

1. a still, within a second;
2. a quick draft (5 pictures a second) of the whole layer, within seconds;
3. the 10 seconds around the playhead (or the start of the part of the layer the clip uses), at full
   frame rate;
4. every other frame, nearest the playhead first. An export waits for this step.

Several copies of Edge share the work (up to 4). The length of step 3 is `html_render_window_secs` in
`settings.json` (default 10).
