![The Keyboard Shortcuts window (F1)](/img/tutorial/cheatsheet.png)

These are the default keys. Every one can be changed in **Settings ▸ Hotkeys**, which also has Premiere, Resolve and Avid presets. In the app, **F1** shows this list with your own keys and a search box, and **Ctrl+K** runs any command by name, including the ones without a key (shown as -).

Keys are written the way the app writes them: `OpenBracket` is `[`, `Semicolon` is `;`, `Quote` is `'`, `Slash` is `/`, `Comma` is `,` and `Backtick` is the key left of 1.

## Mouse

| What it does | How |
|---|---|
| Move | drag clip |
| Move, closing the gap on a magnetic track | drag clip |
| Slip (the content slides, the clip stays) | Alt+drag clip |
| Slide (the neighbours trim to make room) | Ctrl+Alt+drag clip |
| Insert-move (close the gap, open one where it lands) | Ctrl+Shift+drag clip |
| Trim | drag clip edge |
| Ripple trim on a magnetic track | drag clip edge |
| Ripple trim (later clips follow) | Ctrl+drag clip edge |
| Roll the cut | Alt+drag clip edge |
| Rate stretch (change speed to fit) | Shift+drag clip edge |
| Ripple trim every selected clip | Ctrl+Alt+drag clip edge |
| Select the edit point | click cut |
| Select the outgoing side | Ctrl+click cut |
| Select the incoming side | Alt+click cut |
| Add the cut to the trim set | Shift+click cut |
| Select the gap | click empty track |
| Add to the selection with a rubber band | Shift+drag empty track |
| Move the In / Out mark | drag In / Out on the ruler |
| Place on the free track under the pointer | drop from the Library |
| Insert, pushing later clips right | Ctrl+drop from the Library |
| Overwrite what's there | Alt+drop from the Library |
| Place on a new track on top | Shift+drop from the Library |
| Add a clip to the selection or take it out | Ctrl+click clip |
| Add a clip to the selection | Shift+click clip |
| Select a clip without its linked clips | Alt+click clip |
| Split here | click clip with the Blade tool |
| Pan the timeline | middle-drag |
| Zoom the timeline | Ctrl+scroll |
| Scroll the timeline sideways | Shift+scroll |
| Make a track taller or shorter | Alt+scroll |
