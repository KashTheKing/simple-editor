title: Report a bug
description: How to tell us something is broken, in a minute, without knowing anything technical.
---

Found something broken? Reporting it is the most useful thing you can do. It takes about a minute.

## The quick way

1. In Simple Editor open **Help ▸ Report a Bug…**. Your browser opens the bug form on GitHub with your
   version already filled in. (You need a free GitHub account to post it.)
2. Say **what went wrong** and **how to make it happen again**. Short steps like "1. add an MP3, 2. Export,
   3. stuck at 40%" are perfect.
3. Add a screenshot or a short screen recording if you can: drag it into the form.
4. Press **Submit new issue**.

No GitHub account? Describe it in the [Discord](https://discord.gg/6taNJVs5FT) and someone will file it.

## If the app crashed

Simple Editor writes a `crash.log` and keeps your latest autosave. Paste `%APPDATA%\SimpleEditor` into
Explorer's address bar, find `crash.log`, and attach it to the report. It contains a copy of your project's
timeline (clip names and file paths), so open it and check you are happy to share it first. When you start the
app again it offers to recover your work.

## Ideas and questions

- A feature you wish it had: [Suggest a feature](https://github.com/KashTheKing/simple-editor/issues/new?template=feature_request.yml).
- Not sure it is a bug, or just want to chat: the [Discord](https://discord.gg/6taNJVs5FT).
- Already reported? Search the [open issues](https://github.com/KashTheKing/simple-editor/issues) and add a 👍.
