---
name: shorts
description: Turn a clip into a vertical 9:16 short with captions and a hook.
args: "[start-end in seconds, or what the short is about]"
tags: shorts, reels, tiktok, vertical, 9:16, social
credit: hook, caption and safe-zone rules from published short-form guidance and video-use (MIT)
---
Make a vertical short (about 20-60 seconds; Shorts allow up to 3 minutes) from the user's footage: reframed to 9:16, captioned, with a hook in the first seconds. For a whole style pass (cut rhythm, punch-ins, captions) see `/style-shorts`.

1. Call `editor.context` and `project.summary`. Source: the selected clip, else ask. Range: if $ARGS gives `start-end` seconds, use it; if it describes a topic, find it with `transcript.search {query}` (run `transcribe.run {clip_id}` first if there is no transcript); with nothing, pick the strongest 30-45 s stretch from the transcript: one complete idea with a payoff, and say why.
2. The project must be vertical. If it is not 1080x1920, tell the user this changes the whole project's frame and ask whether to change it here. If they agree: `project.set {width: 1080, height: 1920}`. Never do this silently.
3. Open the undo group: `edit.begin {label: "Short"}`. Trim to the range: `timeline.split {t}` at both ends, then `timeline.extract {a, b}` for the parts outside it. Cut between words, never mid-word (use `transcript.get` word times). Remove dead air inside the range with `timeline.auto_cut {clip_ids, threshold_db, min_silence: 0.3, padding: 0.06, ripple: true}` (threshold from `/cut-silences` step 2).
4. Reframe the video: horizontal footage must be scaled up to fill the tall frame. Use `clip.set {clip_id, fields: {scale: ...}}` (roughly 1.8 to 3.2 for 16:9 into 9:16) and shift `x` to centre the speaker. If the clip already has a tracked box, `timeline.reframe {clip_id}` can do it; the app cannot detect faces itself and the call errors cleanly when there is no box. Check with `render.frame {t}` and adjust `x` / `y`. For a moving subject, `clip.keyframe {clip_id, property: "Position X", t, value}`.
5. Safe zones: `guides.list` gives the platforms' UI zones as fractions of the frame. Keep faces, captions and text inside the shared safe box (roughly the middle 80% of the width, from about 15% below the top to about 35% above the bottom); the right-hand button rail and the bottom caption area cover the most. `guides.set {platform}` shows it in the viewer for the user.
6. Captions: build the cues AFTER all cuts: the transcript keeps the original clip's source times, so map each word to the new timeline (piece start + word time - piece `src_in`, using the piece that contains it; word times are approximate, so a word that falls just outside a kept piece belongs to the nearest one: snap it in rather than drop it, and drop only words inside a removed stretch) and write them with `subtitles.set {cues}`, 1-3 words per cue; then `subtitles.style_preset {name}` (`Big Impact`, `Bold Outline` or `Yellow Pop` from `gallery.list {tab: "Captions"}`) and `subtitles.animation {kind: "pop"}`. Short-form cues are 1-3 words, uppercase, at least 0.35 s each (`/captions social` has the rules).
7. Hook (the first 1-2 seconds decide whether people stay): pick the most striking sentence in the range. If it is not already first, either start the short on it or add a text clip with `timeline.add_clip {text, at: 0, duration: 2.5}`, styled with `clip.set` (size, color) and `keyblocks.apply {name: "Pop In", clip_ids: [clip_id], at: 0}`. Keep it under 8 words and about 16 characters per line at size 72 (text clips do not wrap: break lines with `\n`), on a video track above the footage. No logo or slow intro before the hook.
8. Verify: `render.contact_sheet {from: 0, to: <end - 0.1>, count: 12}` and `guides.preview {platform, t}` at a captioned moment. Check the face is in frame, no text sits under the platform UI, and the first 2 seconds grab attention. Then `edit.end`.

What the user asked for: $ARGS

Report back: the range used, its length, whether the project format changed, and the undo steps (the format change is its own step, so a full revert is two Undos). Export with the `Shorts / Reels / TikTok` preset (`export.presets`) when the user asks.
