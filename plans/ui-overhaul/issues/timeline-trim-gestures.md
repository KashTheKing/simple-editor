# Timeline trim gestures: ripple/roll/slip/slide/segment + track lock/ripple/magnetic (undo-free) + gap select + drop modifiers

**Workstream:** `timeline-trim-gestures` · **Issue:** [#30](https://github.com/KashTheKing/simple-editor/issues/30) · **Wave:** 2 · **Branch/worktree:** `feat/timeline-trim-gestures` → `../simple-editor-wt/timeline-trim-gestures` · **Depends on:** trim-model, snap-engine · **~1310 new lines · Δ exe ≈ +95 KB**

Read [agents.md](../../../agents.md), [goals.md](../../../goals.md), [notes.md](../../../notes.md) and the master plan [README.md](../README.md) (registry protocol, keymap, modifier table) before starting.

## Summary

Binds trim-model's wave-1 model primitives to the mouse via snap-engine's arm() table: Ctrl+edge=RippleTrim (ghost during drag, one model call + one undo on release), Alt+edge=Roll, Alt+body=Slip, Ctrl+Alt+body=Slide, Ctrl+Shift+body=Segment (extract+splice, ghost gap, release-applied), Shift+edge=RateStretch. Adds header Lock/Ripple toggle buttons and a Magnetic context-menu checkbox routed through a NEW undo-free deferred field (track_toggle), not Act (every Act pushes one undo unconditionally, confirmed timeline.rs:2338-2339, incl. Mute/Solo). Locked lane gets a new hatch treatment. Adds gap click-select+Delete; Ctrl/Alt/Shift drop modifiers via place_asset with audio-row inference (fixing the Video-only filter at timeline.rs:2361-2362); clip-menu Join Through/Duplicate/Replace/Un-nest. Middle-mouse pan, empty-timeline hint, AND the Body/Shift click-to-add-to-selection fix are snap-engine's wave-1 deliverables, inherited via mod.rs ownership handoff, not rebuilt here (reconcile: this workstream previously re-added the same mods.shift arm as its own audit fix — dropped, see changelog). AUDIT FIX (verified against timeline.rs 2290-2560): the pre-arm auto-select block at drag-start (2500-2507) guards on raw mods.ctrl for BOTH start_move and start_trim with no exclusion for the new Ctrl+Alt (Slide), Ctrl+Shift (Segment), or Ctrl+edge (RippleTrim) meanings — reworked to gate on arm()'s resolved GestureKind so those combos don't also silently replay the old plain-Ctrl-toggle selection as a side effect. Every gesture/act is a 1:1 binding of an already-tooled trim-model op, enforced by gestures_have_tool_twins.

## Motivation

Closes goals.md's editing-grammar gap (rows 24-28, 33-40, 44) without new Tool buttons or new MCP surface. Delivers the frozen modifier_table verbatim: beginner-safe defaults (plain edge/body stay Trim/Move; ripple/magnetic per-track opt-in) alongside pro-depth chords, with header toggles correctly kept out of the undo stack (matching the codebase's real UI-state-vs-edit split, e.g. toggle_graph bypassing Act) rather than the disproven 'matches Mute/Solo' framing. Now also closes a verified selection-modifier gap the frozen table implied but no workstream's diff previously touched: a pre-arm ctrl-toggle block that would fire as an unwanted side effect under the new Ctrl+Alt/Ctrl+Shift/Ctrl+edge gestures. The Shift-click-adds-to-selection gap is snap-engine's wave-1 fix (this workstream inherits it, does not re-author it).

## New types and functions

- `enum Gesture { /* existing: Move,Trim,Stretch,Volume,Fade,Keys,TransDur,Marker,Spacer */ Roll{left:Id,right:Id,cut0:f64,changed:bool}, Slip{ids:Vec<Id>,src0:Vec<f64>,changed:bool}, Slide{id:Id,changed:bool}, RippleTrim{ids:Vec<Id>,start:bool,edge0:f64,dt:f64,changed:bool}, Segment{ids:Vec<Id>,origin:(f64,f64),dt:(f64,f64),changed:bool} }` — src/ui/timeline/mod.rs: New drag states. RippleTrim/Segment carry only a delta (dt) during the drag — no model mutation, no clone — so a 1000-clip ripple costs nothing per frame; the single Project:: call happens once, in the release handler.
- `fn paint_ghost(p: &egui::Painter, pal: &Palette, project: &Project, g: &Gesture, state: &TimelineState)` — src/ui/timeline/gestures.rs: Overlay pass called once after normal clip paint when the live drag is RippleTrim or Segment: draws downstream clips translucently offset by `dt` using pure arithmetic.
- `enum TrackToggleKind { Lock, Ripple, Magnetic }; track_toggle: Option<(usize, TrackToggleKind)>` — src/ui/timeline/mod.rs (TimelineState struct): Deferred, undo-free field applied after the Act match in the SAME pass as the existing `resize: Option<(usize,f32)>` field (timeline.rs:2298-2303) — since every Act variant pushes one undo unconditionally (timeline.rs:2338-2339), including Mute/Solo, routing Lock/Ripple/Magnetic through Act would grow the undo stack on every header click.
- `enum Act { /* existing incl. Mute(usize),Solo(usize) */ CloseGap(usize,f64,f64), DropAssetMode(Id,f64,Option<usize>,DropMode), JoinThrough(Id), Unnest(Id), ReplaceClip(Id) } // DropAsset removed, folded into DropAssetMode; Lock/Ripple/Magnetic excluded from Act` — src/ui/timeline/mod.rs: Local deferred-mutation enum for genuine edits only. Lock/Ripple/Magnetic are excluded because that would incorrectly grow the undo stack for cosmetic/organizational track flags.
- `gap_sel: Option<(usize, f64, f64)>` — src/ui/timeline/mod.rs (TimelineState struct, line ~114-148 pre-split): Selected empty-lane gap (track, a, b), set on a Lane-zone click; Delete with this set fires Act::CloseGap (a real edit).
- `fn drop_mode_for(mods: Modifiers) -> DropMode // Free|Insert|Overwrite|OnTop` — src/ui/timeline/mod.rs: Reads held Ctrl/Alt/Shift at drop time to pick the pre-declared DropMode; passed to edit_ops::place_asset alongside the resolved track (audio-row-aware, fixing the filter at timeline.rs:2361-2362).
- `pub library_selected: Option<Id>` — src/ui/timeline/mod.rs (TimelineCtx struct): New TimelineCtx field, populated by timeline_pane.rs, gating the Replace-with-Library-Selection menu entry.
- `fn arm_selects(kind: GestureKind) -> bool // returns false for Slide/Segment/RippleTrim` — src/ui/timeline/gestures.rs: AUDIT FIX: gate for the pre-arm auto-select block (was raw `if !mods.ctrl` at timeline.rs:2500-2507). Only Move/Trim's original ctrl-toggle-select behavior replays before drag start; the new modifier-driven gestures (Slide=Ctrl+Alt, Segment=Ctrl+Shift, RippleTrim=Ctrl+edge) skip this step since their Ctrl bit means something else, not additive selection.

## Deliberate simplifications (`// ponytail:`)

- Reused existing Glyph::Magnet for the per-track magnetic checkbox instead of adding a duplicate variant.
- Ghost paint for RippleTrim/Segment is pure position arithmetic (offset by dt), not a Project clone + re-run of the trim op every frame.
- Replace-with-Library-Selection reuses whatever's already selected in the Library pane instead of opening an asset-picker dialog (no egui::Modal budget for one anyway).
- GapSelect is a plain click-set Option<(usize,f64,f64)> on TimelineState, not a Drag/Gesture variant.
- JoinThrough/Unnest/ReplaceClip use local Act with an explicit clip_id rather than selection-based global Actions.
- Lock/Ripple/Magnetic header toggles are undo-free UI state routed through a new deferred `track_toggle` field, mirroring the existing `resize` field's ponytail precedent (timeline.rs:2298-2303) — NOT through Act, since Act unconditionally pushes one undo per call (timeline.rs:2338-2339), including Mute/Solo.
- The locked-lane hatch treatment is new visual work, not a reuse of an existing 'muted lane hatch' — hatch() (timeline.rs:644) is currently only called for clip fills (1265, 1267).
- The arm_selects() pre-arm gate is a small, surgical addition to a block this workstream already owns (pre-arm auto-select lives in the same gestures.rs hunk being touched for the new gestures) — no separate file, no new abstraction, just closing the one selection-modifier gap this workstream is the correct owner of. (reconcile: the sibling shift-click-adds-selection fix belongs to snap-engine, which already owns and fixes the click-handling block in wave 1 — inherited here, not re-authored.)
