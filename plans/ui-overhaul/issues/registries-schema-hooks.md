## Summary

Wave-0b infrastructure PR: replaces the 3 hand-kept MCP tool lists with a ToolDef{kind,run} registry and a shared snapshot/rollback core (undo-push kept separate per caller); adds 5 append-only dispatch registries pre-seeded with 23 named workstream sections; lands the schema-first serde fields the 4-wave plan needs on Track/Clip/Asset/Project (Track.volume via a1(), Track.ripple via one shared default_ripple() called from every construction site, Track.color: Option<[u8;3]> and Clip's sole AudioRole definition); pre-places the cross-cutting no-op hooks (enabled, push_undo_labeled, animate_until, SelectionKind/surface, alt_render, place_asset, asset_status, cue_layer_at [borrowed], on_viewport, Pane::Source+stack_unplaced); adds 6 new MCP tools, all registered this wave. Post-audit: Cue.words dropped, Track.color/AudioRole confirmed sole-owned and consumed (not redeclared) by pro-timeline/audio-dsp-automation, animate_until narrowed to new code only, TextStyle gains only reveal/wave: Animated, and this reconcile pass confirmed media_sync.rs's AssetStatus/asset_status shape here is the one media-library must converge onto. Behavior-identical: existing 657 tests, --selftest, a pixel screenshot, and run_script's undo-entry count all stay green; tools/list keeps 70 tools total.

## Motivation

Every wave-1/2/3 workstream's owns_files/touches_shared assumes these extension points already exist: a ToolDef registry (not 3 hand-kept lists), 5 append-only dispatch tables so 22 later PRs never share a match-arm hunk, the schema fields their key_apis reference on Track/Clip/Asset/Project, and the cross-cutting hooks (enabled, push_undo_labeled, animate_until, SelectionKind, alt_render, place_asset, asset_status, cue_layer_at, on_viewport, Pane::Source) named identically across all four phase-2 designs and the critique's architecture hooks. Landing this once, behavior-identical, is what makes 23 workstreams in 4 waves buildable without merge conflicts. This revision closes 5 prior correctness gaps (non-compiling Default bound, unregistered MCP tool, incomplete ripple migration, undo-count regression, per-frame clone) plus this audit round's cross-workstream consistency gaps: one Track.color type/owner, one AudioRole definition, a dropped dead Cue.words field, a narrowed animate_until claim, and — where genuinely safe and additive — the TextStyle/Clip.exposed schema text-titles needs, without importing that workstream's breaking scalar->Animated call-site rewrite into this wave's disjoint, behavior-identical scope. This reconcile pass additionally confirmed this workstream's AssetStatus/asset_status shape is the one media-library's wave-2 revision must converge onto.
